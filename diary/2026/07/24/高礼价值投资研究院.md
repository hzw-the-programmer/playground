# 一、基础定位与背景区分

## 1、主体信息

全称：高礼价值投资研究院（Hillhouse Value Investment Institute）

2017 年由高瓴资本（Hillhouse）发起创办，对标美国哥伦比亚大学格雷厄姆 - 多德价值投资研究中心，是国内顶尖、只面向资深职业投资人的封闭式价值投资学习社群，非面向散户、非理财培训机构。

核心管理层架构：

- 名誉理事长：大卫・史文森（耶鲁捐赠基金首席投资官，全球机构投资教父）

- 理事长：张磊（高瓴创始人）

- 院长：邱国鹭（高毅资产董事长）

## 2、注意区分两个 “高礼”（极易混淆）

高礼价值投资研究院：面向在职职业投资人（公募 / 私募 / 一级市场从业者），社会市场化研习班；

人大高礼研究院：2011 年张磊捐建在中国人民大学，面向在校本科生，开设金融科技双学位，属于高校校内项目，和投资人研习班是两套独立体系，无学员互通。

# 二、创立初衷

国内价值投资落地断层：很多人只懂理论，缺乏横跨一二级、产业结合的实战训练；

搭建顶尖投研交流圈：打通一级市场（高瓴）、二级市场（高毅）、实体企业家资源；

传播长期结构性价值投资，纠正市场短期博弈、题材炒作风气，强调 “创造价值、做时间的朋友”。

# 三、研习班招生规则（核心门槛，普通人无法报名）

## 1、招生标准

1）仅限从业 5 年以上专业投研人：公募 / 私募基金经理、行业首席、PE/VC 投资总监、上市公司董秘 / 实业 CEO；

2）崇尚基本面价值投资、具备独立深度研究能力；

3）每年全球报名近千人，仅录取 25–30 人，小而美精英模式；

4）选拔三层：简历 + 自荐信→提交行业深度研报 + 视频问答→终面面试，需 2 封行业大佬推荐信。

## 2、学制与费用

学制：2 年 “1+1 模式”

第 1 年：每月 1 次线下周末授课，北上深三地巡回；

第 2 年：实践互动期，无固定上课，小组课题持续跟踪、终身社群交流；

费用：总学费 30 万，公益属性，营收全部用于教研；顶尖优秀从业者可全额奖学金减免；

非脱产：学员全职正常上班，利用周末学习。

# 四、课程体系（实战导向，纯案例教学）

## 1、顶级师资阵容

1）内部核心讲师：

- 张磊：一级市场长期价值、产业赋能、消费 / 零售赛道；
- 邱国鹭：价值投资底层框架（估值、品质、时机、护城河）；
- 邓晓峰、冯柳、卓利伟（高毅明星基金经理）：TMT、消费、周期行业实战；
- 高瓴各行业合伙人：医药、硬科技、新能源一级投资逻辑。

2）外部客座：

海外价值投资大师、上市公司创始人、监管、行业专家、耶鲁 / 哥大商学院教授。

## 2、三大核心教学模块

1. 价值投资底层方法论

邱国鹭核心框架：好生意（护城河、定价权）、好公司、好价格；逆向投资、如何分辨 “长坡厚雪” 赛道、规避估值陷阱；

2. 跨市场案例研讨（最大特色：打通一二级）

每组每月完成行业 / 公司深度课题，比如：格力、隆基、医药龙头、AI 产业链复盘；

一级看产业长期空间，二级看估值与买点，打破一二级市场认知壁垒；

3. 企业家对话与实地调研

走进龙头上市公司实地走访，和创始人面对面交流，理解企业真实经营，避免纸上谈兵；

## 3、标志性理念输出

院内高频核心观点：

1. Intellectual honesty（认知诚实）：客观承认自己的能力圈、错误；
2. 投资不是博弈，是分享企业长期成长价值；
3. 数月亮，不数星星：优先格局清晰、龙头稳固的赛道，规避碎片化竞争；
4. 价值投资分两层：发现价值（低估买入）、创造价值（赋能企业成长，高瓴特色）。

# 五、研究院产出与价值

1. 投研圈层资源

历届学员覆盖头部公募、百亿私募、一线 PE、A 股龙头实业高管，形成国内顶级价值投资人社交网络；

2. 公开内容沉淀

公众号持续发布课堂实录、研报精选、大师对话；流传全网的邱国鹭《价值投资数月亮》、张磊投资逻辑演讲都出自院内课程；同时整
理经典价值投资必读书单（格雷厄姆、巴菲特、史文森、国内实战著作）；

3. 行业影响力

推动国内机构资金转向长期持有、基本面研究，弱化短线交易；很多学员毕业后在各大资管担任核心投研负责人，持续传播价值体系。

# 六、客观局限

极高准入门槛：散户、在校生、无投资从业经历完全无法报名；

课程偏机构大资金视角，不适合小散炒股实操；

研习班仅开办前 4 期（2017–2020 年集中招生），近年不再公开大规模招新，以往届校友闭门交流为主，外部普通人几乎没有参与渠道。

# 七、和市面上普通价值投资培训班核心区别

维度	高礼价值投资研究院	市面理财 / 股票培训班
学员	5 年以上职业基金投研人	普通散户、理财小白
师资	千亿资管创始人、一线实战基金经理	自媒体讲师、无实盘大资金经验
内容	产业深度复盘、一二级联动、企业实地调研	K 线、短线战法、择时抓涨停
目的	培养机构专业投资者	吸引散户付费荐股、卖课程
盈利属性	公益运营，学费仅覆盖成本	商业化盈利，推销付费社群、股票服务

# 总结

高礼价值投资研究院是国内职业价值投资圈的顶级闭门学堂，由高瓴、高毅两大头部资管联合打造，核心作用是给资深从业者搭建高端学习、交流平台，普及长期基本面投资；对普通个人投资者来说，无法报名参与，但可以通过公众号公开文章、演讲实录学习其价值投资框架。
