# 一、基础背景

创立者：罗伯特・希勒（Robert Shiller），2013 年诺贝尔经济学奖得主、《非理性繁荣》作者，2019 年出版专著《叙事经济学》正式确立这套理论框架。

定位：行为经济学分支，弥补传统经济学 “理性人” 假设的缺陷；凯恩斯提出的 “动物精神” 只承认情绪影响经济，希勒更进一步：传播的故事（叙事）才是情绪与经济波动的源头。

核心定义

叙事经济学：研究**大众流行叙事的病毒式传播规律**，解释故事如何改变全社会消费、储蓄、投资行为，进而驱动经济周期、资产泡沫、衰退萧条。

- 叙事≠小说：可以是口号、段子、行业神话、谣言、政策解读、暴富案例、悲观预言；

- 关键特征：**容易转述、带有强烈情绪、简化复杂现实、能指导行动**；

- 核心比喻：叙事如同病毒，借用流行病学 **SIR 模型**分析生命周期（易感人群→感染传播→免疫消退）。

# 二、五大核心底层观点

1. 叙事本身是独立的经济变量

传统经济学把故事当成经济结果（股市涨了才出现牛市故事）；希勒反向论证：**故事先行，行为跟随，数据随后变动**。

例：先流传 “AI 将重塑所有行业” 叙事→资金加仓算力 / 芯片→板块上涨（数据），上涨又反过来强化叙事，形成正向循环。

2. 叙事像病毒有完整生命周期

- 潜伏期：小众圈层流传，传播力弱；

- 爆发期：媒体、网红、机构放大，全民共识，资金大规模行动；

- 饱和期：易感人群全部入场，新增传播放缓；

- 衰退免疫：负面现实证伪叙事，大众不再相信，故事消亡。

3. 叙事集群效应（叙事星座）

单一故事很难长期发酵，**一组关联叙事互相支撑才会形成长期大行情**。

举例 2021 年新能源牛市叙事集群：

①碳中和全球政策；②新能源车渗透率加速提升；③锂矿资源稀缺；④欧美补贴加码；⑤储能万亿空间。多条故事互相印证，持续推高估值。

4. 叙事会变异迭代

传播中故事自动简化、添油加醋、适配当下舆论，增强传播力。

比特币叙事演变：早期 “去中心化匿名支付”→中期 “对抗通胀数字黄金”→后期 “Web3 底层资产”，不断迭代维持热度。

5. 叙事主导顺周期反馈（泡沫 / 萧条根源）

- 繁荣正向循环：乐观叙事→加大投资 / 消费→经济向好→强化乐观叙事；

- 萧条负向循环：“要经济下行、失业潮” 悲观叙事→全民存钱、企业裁员扩产停滞→衰退落地，恐慌叙事进一步扩散。

# 三、经典历史案例

1. 1929 年大萧条

崩盘后全民流传 “过度负债必遭清算、存钱保命” 叙事，居民疯狂储蓄、企业停止投资，政府刺激政策难以扭转悲观共识，萧条持续多年。

2. 郁金香泡沫

“稀有球茎永久升值、转手暴富” 故事全民传播，普通人借贷入场，叙事破灭后价格崩盘。

3. 比特币

十年间靠多轮叙事更迭，多次牛熊切换；每当通胀、美元贬值叙事升温，加密资产行情同步启动。

4. A 股市场落地场景

- 2007：“中国股市黄金十年” 叙事催生 6124 点大牛市；

- 2015：“国家牛市、杠杆无风险” 叙事引爆杠杆牛；

- 2023 至今：AI 自主可控、算力刚需叙事持续驱动科技行情。

# 四、叙事如何直接影响三类经济决策

1. 居民消费

“经济不好要存钱”→缩减大宗消费；“消费升级是必然趋势”→主动买房、换车、奢侈品消费。

2. 企业投资扩产

行业长期向好叙事→企业大举建厂、招聘；衰退叙事→收缩资本开支、裁员降本。

3. 资本市场投资

资产增值叙事带来增量资金，悲观叙事引发集体抛售；**估值泡沫本质是叙事溢价**，和企业真实盈利脱节。

# 五、和传统经济学、行为经济学的区别

1. 传统古典经济学

只看供需、利率、GDP、企业盈利；假设人理性，忽略大众舆论与故事，无法解释非理性泡沫与长期萧条。

2. 行为经济学（动物精神）

承认人有恐慌、贪婪、从众心理，但不解释情绪从哪里来；

3. 叙事经济学

往前溯源：情绪来自传播的故事，重点研究故事如何扩散、发酵、消退，可跟踪、可预判周期拐点。

# 六、现实应用（投资 / 宏观分析）

1. 股票赛道分析

每一轮主线行情的核心是最强叙事集群：

- 高位风险信号：叙事全民皆知，无新增故事迭代，利好落地无法再推升股价；

- 左侧机会信号：优质叙事刚在小众圈层传播，大众尚未形成共识。

2. 宏观经济预判

监测全网悲观 / 乐观叙事热度：

居民普遍流传失业、降薪故事时，消费复苏会显著低于数据预期；产业长期增长叙事稳固时，制造业投资韧性更强。

3. 风险规避

警惕**脱离基本面的纯叙事泡沫**：企业盈利无法支撑故事描绘的空间，一旦叙事降温，估值会快速回归。

# 七、局限性（客观短板）

1. 难以精准量化：故事传播强度只能通过搜索指数、舆情文本近似衡量，不如财务数据精确；

2. 叙事存在误导性：大量流传故事夸大、片面、不符合事实，容易造成集体误判；

3. 长期基本面终会纠偏：叙事只能短期驱动行情，长期资产价格仍回归企业盈利、供需等真实基本面。

# 八、一句话总结叙事经济学

短期市场看故事，中期故事看资金，长期资金看基本面；所有经济大波动，都是一场故事的病毒式传播与落幕。
