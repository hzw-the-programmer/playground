# 一、基础定位与办学背景

## 1. 学校性质

西湖大学（Westlake University）坐落杭州，**新中国第一所社会力量举办、国家重点支持的新型非营利研究型大学**，由海归科学家群体发起、杭州市西湖教育基金会运营，教育部与浙江省共建，不属于传统公办 985/211 / 双一流，但享受国家级重点科研扶持。

- 前身：2016 年成立浙江西湖高等研究院
- 正式获批建校：2018 年 2 月，首任校长施一公院士（生物物理顶尖学者）
- 办学方针：高起点、小而精、研究型，不搞大规模大众化培养，专注基础前沿、硬核科技原始创新

## 2. 两大校区

1. 云谷校区（主校区，1495 亩）：本科生、大部分科研实验室、行政核心区，环形水系园林式校园；

2. 云栖校区（93 亩）：早期研究院、部分生物医学平台、博士后工作站。

# 二、院系、学科与专业设置

四大学院，8 大本科专业，8 个一级学科

1. 理学院

专业：数学与应用数学、物理学、化学

方向：基础数理、量子物理、合成化学、天文（2025 新设天文系）

2. 工学院

专业：材料科学与工程、电子信息工程、人工智能

方向：半导体、芯片、机器人、AI 大模型、先进材料

3. 生命科学学院（王牌）

专业：生物科学

全国顶尖，结构生物学、细胞生物、生物医药，第五轮学科评估 A 类（全国前 5%）

4. 医学院（2023 年成立）

专业：临床医学

配套三甲附属医院：杭州市第一人民医院，基础医学 + 临床转化一体化

交叉特色学科：定量生物学、可持续发展科技、多尺度天体物理

# 三、师资力量（核心竞争力）

截至 2025 年底，全职科研教授 270 + 人、博导 280 + 位：

1. 90% 以上导师海外名校全职任教经历，70% 来自全球 TOP50 高校；

2. 40 余名讲席教授，176 人拥有国家级人才头衔；

3. 阵容覆盖中科院院士、海外院士、新基石研究员、科学探索奖得主；

4. 大量 MIT 科技评论 35U35 青年创新人才，年轻化、国际化程度国内顶尖。

> 特点：师生比极低，本科生一人可匹配专属科研导师，大一下即可进实验室。

# 四、招生体系（本科 + 硕博）

1. 本科招生（2026 覆盖 9 省市）

招生省份：浙江、上海、江苏、广东、重庆、河南、山东、安徽、江西

- 录取方式：综合评价为主，少量普通高考，极度看重理科思维、科研潜质；

- 学费：6000 元 / 年（公办同价，并非网传高价民办）；

- 住宿：单人卧室套间（四室两厅户型），住宿费 1800-2200 / 年；

- 培养模式：书院制 + 本硕博贯通，保研 / 直博率接近 100%，大量学生拿到斯坦福、MIT、剑桥海外全奖博士 offer；

- 学制 4 年，毕业颁发西湖大学正规本科毕业证、学士学位证。

2. 硕博研究生（建校起点，核心优势）

- 2022 年起独立授予博士学位，此前与复旦、浙大联合培养；

- 所有博士生全额奖学金覆盖学费 + 生活补贴，无经济压力；

- 招生方向：生物、化学、物理、数学、电子、材料、AI、临床医学；

- 博士后规模庞大，配套顶级实验平台，适合走学术路线。

# 五、核心优势

1. 科研资源极度集中

单校科研经费对标中游 985，配套分子生物、半导体、AI 超算、医学转化全套顶尖设备；国家发改委立项未来产业中心，已孵化 60 余家硬科技创业公司（生物医药、芯片、新材料）。

2. 国际化程度断层领先

与 Science、AAAS 等国际顶级期刊深度合作，频繁海外交换、联合培养，导师全球学术网络极强。

3. 人才培养模式超前

不唯应试，重视独立科研、交叉学科；无僵化分科，允许跨学院自由选课、跨导师做课题。

4. 赛道精准踩国家战略

完全布局卡脖子领域：芯片半导体、基础生物、AI 底层算法、先进材料、临床医学，契合国产替代、生物医药自主可控大方向。

# 六、短板与客观不足

- 建校时间短（仅 8 年），大众传统知名度不如老牌 985，体制内部分传统岗位认知仍在培育；

- 规模极小，每年本科新生仅几百人，没有文科、经管、法学等专业，学科单一；

- 培养导向高度偏向科研，不适合只想拿文凭、就业不打算深造的学生；

- 临床医学专业刚起步，临床积累远不如老牌医科大学。

# 七、升学 & 就业去向

1. 深造（本科主流）

70% 以上直博：本校 / 清华北大 / 复旦上交；30% 海外名校全奖博士（斯坦福、普林斯顿、剑桥、苏黎世理工等）。

2. 就业（硬科技高端岗位）

- 芯片：海思、中芯、寒武纪、长鑫存储；

- AI：阿里达摩院、字节、华为诺亚方舟实验室；

- 生物医药：恒瑞、药明康德、创新药企研发岗；

- 体制：中科院各院所、国家重点实验室、高校教职。

# 八、适合 / 不适合报考人群

✅ 推荐报考

1. 数理化生基础极强，热爱基础 / 前沿科研，计划读博走学术路线；

2. 目标芯片、AI、生物医药、新材料等硬核科技研发；

3. 自律、愿意长期泡实验室，不追求综合类大学丰富文科社团资源。

❌ 不推荐

1. 只想读本科直接就业、无读博规划；

2. 想学文科、经管、师范、艺术类专业；

3. 追求老牌名校口碑、稳定体制内传统岗位。

# 九、同类院校对比（南科大 / 上科大 / 西湖大学）

1. 西湖大学：科研天花板，基础生物、前沿物理、芯片最强，主打博士学术路线；

2. 南方科技大学：深圳区位，工科就业强，政企资源丰富；

3. 上海科技大学：背靠中科院，生物医药、微电子产业化优势突出。
