# 赤と青（あかとあお / Aka to Ao）

出自《**スーパーの裏でヤニ吸うふたり｜超市后门吞云吐雾二人**》动画 **正式版 ED**

> 
> 歌手：羊文学
> 替换掉出圈先行 ED《NIGHT DANCER》，作为 TV 动画片尾。

## 基础信息

- 歌名：赤と青（红与蓝）
- 演唱：羊文学（Hitsuji Bungaku）
- 作词作曲：塩塚モエカ
- 曲风：日系另类摇滚，温柔带怅然，压抑又舒展，比 `NIGHT DANCER` 更沉、更贴原作苦涩成年人氛围。
- 意象：**红＝夜晚后门烟头的火光；蓝＝都市夜色、黄昏、夜晚的天空**，刚好对应整部作品最核心两套视觉符号。

## 核心意象解读

- **赤（红）**：烟头燃烧的橘红火星、短暂热烈、转瞬即逝、后门的私密时刻、两个人跳动的情绪。烟火会熄灭，欢愉是限时的。
- **青（蓝）**：城市夜幕、薄暮灰蓝、现实世界、白天的社会面具、日常的重压，是永恒笼罩他们的现实底色。

> 
> 歌的内核：**在冰冷蓝色现实之中，捕捉那一点转瞬的红色微光**。后门的相遇，就是茫茫蓝色日常里小小的红色火种。

### 歌词对应剧情

1. **赤と青が混ざり合ってく 红与蓝交融**
夜色（蓝）笼罩后门，烟头火光（红）摇曳；佐佐木和田山，「顾客‑店员」的社会身份与「卸下伪装的自我」互相交织。两个身份世界在此处重叠。
2. **何処へだって行けそうな気がした / でもまだここに立っている**
在后门相处的片刻，仿佛逃离一切枷锁，获得自由；但夜晚终会结束，天亮必须回归现实职场、社会身份，不能永远沉溺这片夹缝。
这就是本作最大宿命感：**避难所是短暂的，现实不会消失**。
3. **君と見た夕暮れは二度と忘れはしないよ**
黄昏转夜晚，是二人后门相会的固定时间。黄昏转瞬即逝，就像他们珍贵的相处时光。哪怕未来秘密揭开、关系发生变化，这些夜晚记忆不会磨灭。

## ED 画面分镜对应

1. 开篇：黄昏蓝调天空，超市建筑轮廓，慢慢入夜；
2. 交替剪辑：白天明亮超市内（山田营业微笑） / 昏暗后门（田山抽烟、佐佐木）；
3. 特写：烟头跳动红色火光，烟雾在蓝色夜色里飘散，红与蓝光影交织；
4. 大量侧脸、剪影，两人很少对视，安静并排；
5. 结尾：天色彻底变黑，镜头拉远，超市灯火溶入城市，两人小小的身影消融在夜色。

## 《Night Dancer》vs《赤と青》对比

表格

| 项目     | Night Dancer（先行 ED）             | 赤と青（正式 TV ED）                    |
| -------- | ----------------------------------- | --------------------------------------- |
| 曲风     | City‑Pop 轻快律动，表面欢快内里落寞 | 另类摇滚，沉静忧伤，情绪向内收敛        |
| 核心意象 | 夜晚可以短暂起舞、逃离现实          | 红（烟火微光）与蓝（现实夜色）的对冲    |
| 气质     | 幻想感，浪漫的夹缝出逃              | 更贴近原作漫画现实压抑感                |
| 出圈度   | TikTok 全球爆火，二创无数           | 动画正片 ED，日本本土口碑高，海外热度低 |

> 
> 很多观众的感受：`NIGHT DANCER` 是理想中浪漫的后门故事；**《赤と青》才是原作真正的底色**—— 美好是微弱、易碎，始终被现实包裹。
