# 伯努利分布（Bernoulli Distribution）

## 1. 定义

**伯努利试验：只做 1 次试验，结果只有 2 种：成功 (1) / 失败 (0)**。
是最简单的离散概率分布。

参数：p，单次试验成功的概率，\(0\le p \le 1\)。
随机变量 \(X\in\{0,1\}\)

**概率质量函数 PMF**

\(\begin{cases}
P(X=1)=p \\
P(X=0)=1-p
\end{cases}\)
统一写成紧凑形式：

\(P(X=x)=p^{x}\,(1-p)^{1-x},\quad x\in\{0,1\}\)

## 2. 均值与方差

\(\mathbb E[X] = p\)\(\mathrm{Var}(X)=p(1-p)\)

## 3. 和其他分布的关系

1. **伯努利 \(\iff\) K=2 的分类分布 (Categorical)**
   - Categorical：K类一次试验；当\(K=2\)就退化成伯努利。
   - Categorical 参数向量 \(\boldsymbol p=[p,1-p]\)。
2. **二项分布 (Binomial)**：n次独立重复伯努利试验。
   - 伯努利就是 \(n=1\) 的二项分布。

> 
> 小结三层嵌套：
> 
> 
> - 伯努利：\(n=1,K=2\)
> - 分类分布 Categorical：\(n=1,K\)
> - 二项分布：\(n,K=2\)
> - 多项分布 Multinomial：\(n,K\)

表格

| 分布             | 试验次数 | 类别数 K | 取值         |
| ---------------- | -------- | -------- | ------------ |
| 伯努利           | \(n=1\)  | \(K=2\)  | \(0,1\)标量  |
| 二项             | n次      | \(K=2\)  | 成功总次数   |
| 分类 Categorical | \(n=1\)  | K        | 类别索引     |
| 多项 Multinomial | n次      | K        | 各类计数向量 |

## 4. 深度学习视角

伯努利常用于**二分类**。
神经网络输出 logit（未经过 sigmoid）：z
经过 \(\boldsymbol{\sigma}\) sigmoid 得到成功概率：

\(p=\sigma(z)=\frac{1}{1+e^{-z}}\)

损失函数：**二元交叉熵 BCE**
极大似然等价：

\(\mathcal L = -\big[y\log p + (1-y)\log(1-p)\big]\)
\(y\in\{0,1\}\) 是 0‑1 标签。

> 
> ⚠注意区分：
> 
> 
> - 多分类：Categorical + Softmax + 多类交叉熵；
> - 二分类（独立）：Bernoulli + Sigmoid + BCE；
> 二分类任务也可以当成 K=2 的 Categorical+Softmax，两种写法等价，但实现细节有差异。

## 5. PyTorch 示例

```python
import torch
from torch.distributions import Bernoulli

p = torch.tensor([0.7])
dist = Bernoulli(probs=p)
x = dist.sample()       #采样0或1
log_p = dist.log_prob(x)
```

> 
> Bernoulli 既可以接收`probs`，也可以接收`logits`（直接输入 sigmoid 前的值）。

## 6. 补充性质

1. 属于**指数族分布**；
2. 本身采样是离散，**不可导**；如果需要重参数化，伯努利没有原生重参数技巧；
3. 当输出是多维独立 0‑1 向量（每个位置独立伯努利），就是独立伯努利；比如多标签分类，每一类是独立的伯努利，用 sigmoid，不是 softmax。
