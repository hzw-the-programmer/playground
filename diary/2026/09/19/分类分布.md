# 分类分布（Categorical Distribution，也叫类别分布）

> 
> ⚠️注意区分：**分类分布 Categorical（单次试验，多类）** vs **多项分布 Multinomial（重复 n 次分类试验）**；很多教材容易混淆。

## 1. 定义

分类分布是**离散多值的概率分布**，描述做**1 次随机试验**，结果只能取 K 个离散类别其中之一。

设一共 K 个类别；概率向量：

\(\boldsymbol p=(p_1,p_2,\dots,p_K),\quad \sum_{i=1}^K p_i=1,\;p_i>0\)

随机变量 \(X\in\{1,2,\dots,K\}\)，概率质量函数 PMF：

\(P(X=i)=p_i\)

也可以用**one‑hot 独热向量**形式表示输出 \(\boldsymbol x \in \{0,1\}^K\)，恰好一个位置是 1：

\(P(\boldsymbol x)=\prod_{i=1}^K p_i^{x_i}\)
\(\sum x_i=1\)，这是最常用的形式（深度学习里）。

### 简单例子

K=2 时分类分布就退化为**伯努利分布**：\(\boldsymbol p=(p,1-p)\)。

- \(P(X=1)=p,\;P(X=2)=1-p\)

> 
> 伯努利：2 类、1 次；Categorical：K 类、1 次；Multinomial：K 类、独立重复n次。

## 2. 和多项分布对比表

表格

| 分布             | 试验次数           | 输出                                  |
| ---------------- | ------------------ | ------------------------------------- |
| 伯努利 Bernoulli | \(n=1,K=2\)        | 0/1 标量                              |
| 分类 Categorical | \(n=1,K\)          | 类别标号 /one‑hot 向量                |
| 多项 Multinomial | n次独立重复K类试验 | K维计数向量\((c_1...c_K),\sum c_i=n\) |

多项分布 PMF：

\(P(C_1=c_1...C_K=c_K)=\frac{n!}{c_1!\dots c_K!}\prod_{i=1}^K p_i^{c_i}\)
当 \(n=1\)，多项分布等价分类分布（此时阶乘项\(\frac{1!}{1!0!...}=1\)）。

## 3. 深度学习里的用法

- 神经网络最后一层输出 logits（未归一化得分 \(z_1...z_K\)）；
- **Softmax**把 logits 转成分类分布的概率：

\(p_i=\text{softmax}(\boldsymbol z)_i=\frac{e^{z_i}}{\sum_{j=1}^K e^{z_j}}\)

- 损失函数：**交叉熵损失（针对分类分布）**

\(\mathcal L=-\log p_{y_{\text{true}}}=-\sum_{i=1}^K y_i\log p_i\)
y是真实 one‑hot 标签。

> 
> 重点：
> 
> 
> - Categorical 分布的参数就是 softmax 输出的概率向量；
> - pytorch/tensorflow 里 `Categorical(logits=...,probs=...)` 直接实现该分布，可以做采样。

### PyTorch 极简示例

```
import torch
from torch.distributions import Categorical

probs = torch.tensor([0.1,0.5,0.4])
dist = Categorical(probs=probs)
sample = dist.sample()       # 采样一个类别索引
logp = dist.log_prob(sample) #取该样本对数概率
```

## 4. 均值方差

设类别取值为\(1,2,...,K\)：

\(\mathbb E[X]=\sum_{i=1}^K i\,p_i\)
\(\mathrm{Var}(X)=\sum_{i=1}^K i^2 p_i - (\mathbb E[X])^2\)> 
> 在深度学习 one‑hot 视角，更常用**期望向量** \(\mathbb E[\boldsymbol x]=\boldsymbol p\)。

## 5. 补充要点

1. 分类分布属于**指数族分布**；
2. 支持域是有限离散集合\(\{1,\dots,K\}\)；
3. 离散采样：Gumbel‑Max 重参数化，就是对 Categorical 做可导近似（Gumbel‑Softmax）；解决 Categorical 本身不可导无法反向传播的痛点。
