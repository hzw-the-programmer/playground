# 多项分布 Multinomial Distribution

## 1. 定义

**独立重复 n 次分类 (Categorical) 试验**；每次试验有 K 个互斥类别，单次各类概率：\(p_1,p_2,\dots,p_K\)，满足

\(\sum_{i=1}^K p_i =1,\quad p_i>0\)

随机向量 \(\boldsymbol X=(X_1,X_2,\dots,X_K)\)
\(X_i\)：n 次试验中第 i 类出现的次数，约束：

\(X_1+X_2+\dots+X_K = n\)

**概率质量函数 PMF**

\(P(X_1=x_1,\dots,X_K=x_K)
=\frac{n!}{x_1!\,x_2!\cdots x_K!}\;
\prod_{i=1}^K p_i^{x_i}\)
其中 \(x_i\) 是非负整数，\(\sum x_i=n\)。

> 
> 🧩特例关系：

1. \(n=1\)：多项分布 \(\Rightarrow\) **分类分布 Categorical**；阶乘系数等于 1；
2. \(K=2\)：多项分布 \(\Rightarrow\) **二项分布 Binomial**。

## 2. 均值、协方差（⚠️注意不是方差，是协方差矩阵！）

期望向量：

\(\mathbb E[X_i]=n\,p_i\)

协方差（同一个变量方差、不同变量协方差）

\(\begin{cases}
\mathrm{Var}(X_i)=n\,p_i(1-p_i)\\
\mathrm{Cov}(X_i,X_j)=-n\,p_i p_j \quad(i\neq j)
\end{cases}\)> 
> 协方差是负数：一类计数变多，其余总和必然变少，存在负相关。

## 3. 家族总回顾（一张总表）

表格

| 分布                 | 试验次数n | 类别K   | 随机变量 / 向量                           |
| -------------------- | --------- | ------- | ----------------------------------------- |
| 伯努利 Bernoulli     | \(n=1\)   | \(K=2\) | 标量\(X\in\{0,1\}\)                       |
| 二项 Binomial        | n         | \(K=2\) | 标量：成功总次数                          |
| 分类 Categorical     | \(n=1\)   | K       | 类别索引 (1 次多类)                       |
| **多项 Multinomial** | n         | K       | 计数向量\(\boldsymbol x\)，\(\sum x_i=n\) |

层级链条：

\(\text{Bernoulli}
\stackrel{n>1}{\longrightarrow}\text{Binomial}\)
\(\text{Categorical}
\stackrel{n>1}{\longrightarrow}\text{Multinomial}\)
\(\text{Binomial}\stackrel{K>2}{\longrightarrow}\text{Multinomial}\)
\(\text{Bernoulli}\stackrel{K>2}{\longrightarrow}\text{Categorical}\)## 4. 深度学习视角

- 多项分布是**n 次独立 softmax 采样后的计数结果**。
- 深度学习绝大多数时候**n=1**，直接用 Categorical（单样本多分类）；
- 多项分布对数似然：

\(\log P(\boldsymbol x)=\log\left(\frac{n!}{\prod x_i!}\right)+\sum_{i=1}^K x_i\log p_i\)
\(\log\)阶乘项只跟观测x有关，跟模型参数\(\boldsymbol p\)无关；做极大似然优化可以直接丢掉，剩下 \(\sum x_i\log p_i\)。

> 
> 当 \(n=1\)，\(\boldsymbol x\)是 one‑hot 向量，\(\sum x_i\log p_i = \log p_{y}\)，等价多分类交叉熵。

⚠️区分任务：

- 多分类单样本预测：**Categorical + Softmax + 交叉熵**（n=1）
- 做 n 次重复多类试验统计每一类出现多少次：**Multinomial**

## 5. PyTorch 示例

```python
import torch
from torch.distributions import Multinomial

# n=10次试验，K=3类概率
dist = Multinomial(total_count=10, probs=torch.tensor([0.1,0.3,0.6]))
sample = dist.sample()   #输出 [x1,x2,x3], sum=10
logp = dist.log_prob(sample)
```

`total_count`就是试验总次数n；同样支持`logits`输入。

## 6. 指数族形式

\(P(\boldsymbol x)=\frac{n!}{\prod x_i!}\exp\left(\sum_{i=1}^K x_i\log p_i\right)\)自然参数 \(\eta_i=\log p_i\)；受约束 \(\sum p_i=1\)，属于**带约束的指数族分布**。
