# 从 KeyShareEntry 公钥 → TLS‑1.3 主密钥完整链路

> 
> RFC‑8446 §7 密钥派生流程，输入：客户端临时私钥、服务端 `KeyShareEntry.key_exchange`（对方公钥）；输出 `secret` 系列，用于握手密钥、应用密钥。

## 前置符号

- `dh(sk, pk)`：ECDH 原始共享点运算
  - sk：本端临时私钥
  - pk：对端 `KeyShareEntry.key_exchange` 公钥字节
- `HKDF‑Extract(salt, ikm)`
- `HKDF‑Expand(prk, info, len)`
- `zero‑32`：32 字节全 0 字节串
- `transcript`：握手全部消息的哈希，**从 Client Hello 开始直到当前点的握手消息哈希**，哈希算法由 cipher suite 确定（SHA256 / SHA384）

> 
> 全部 HKDF 使用 TLS 1.3 指定 HMAC‑Hash，Hash 跟随密码套件。

## 步骤 1：ECDH 计算共享密钥

双方各自拿自己临时私钥，对方 `KeyShareEntry` 的公钥执行 ECDH：

```
shared_secret = dh(local_ephemeral_sk, remote_key_share.key_exchange)
```

- X25519：直接输出 32 字节，无点压缩解压额外步骤
- secp256r1：先把 `key_exchange` 解压为椭圆曲线点，再做 ECDH，得到 32 字节共享秘密

> 
> shared_secret 是 IKM，还不是密钥，必须经过 HKDF 处理，**不能直接当加密密钥用**。

## 步骤 2：HKDF‑Extract 得到 Early Secret → Handshake Secret

TLS1.3 是链式 Extract：

```plaintext
early_secret = HKDF‑Extract(salt=zero‑32, ikm=PSK)
# 如果没有 PSK：PSK = zero‑32，early_secret 依然计算

handshake_secret = HKDF‑Extract(
    salt=HKDF‑Expand(early_secret, "derived", HashLen),
    ikm=shared_secret
)
```

- `"derived"` 是固定 info 标签字节串：`0x64 65 72 69 76 65 64`
- HashLen：哈希输出长度，SHA256=32，SHA384=48

> 
> `handshake_secret` 来自 ECDH shared_secret + early_secret，是握手阶段根密钥。

## 步骤 3：由 handshake_secret 派生 client/server handshake traffic secret

用 HKDF‑Expand，info 为固定标签：

```
client_handshake_traffic_secret =
    HKDF‑Expand(handshake_secret, "c hs traffic", HashLen)

server_handshake_traffic_secret =
    HKDF‑Expand(handshake_secret, "s hs traffic", HashLen)
```

基于这两个 secret，再 Expand 得到：

- 握手阶段的 AES/GCM 密钥
- nonce

> 
> 用于加密：EncryptedExtensions、Certificate、CertificateVerify、Finished 消息。

## 步骤 4：Master Secret 派生

握手 transcript 哈希 `handshake_hash`：覆盖从 ClientHello 到 ServerHello + EncryptedExtensions + … + Server Finished 之前全部握手消息。

```
master_secret = HKDF‑Extract(
    salt=HKDF‑Expand(handshake_secret, "derived", HashLen),
    ikm=zero‑32
)
```

再从 master_secret Expand：

```
client_application_traffic_secret_0 =
    HKDF‑Expand(master_secret, "c ap traffic", HashLen)

server_application_traffic_secret_0 =
    HKDF‑Expand(master_secret, "s ap traffic", HashLen)
```

这一组就是**应用数据加密密钥根**，后续发送应用数据就基于这组做密钥派生。

最后还要生成 `finished_key`，用于 Finished 消息校验握手完整性：

```
finished_key = HKDF‑Expand(base_secret, "finished", HashLen)
```

客户端、服务端各自使用对应 traffic secret 派生 finished_key，输出 HMAC 校验值，防止握手被篡改。

---

## 数据流简图

```
KeyShareEntry.key_exchange (peer pubkey)
        ↓ ECDH(local_ephemeral_sk)
shared_secret
        ↓ HKDF‑Extract + early_secret
handshake_secret
        ↓ HKDF‑Expand
├─ client_handshake_traffic_secret → 握手密钥、nonce、finished_key
└─ server_handshake_traffic_secret → 握手密钥、nonce、finished_key
        ↓ HKDF‑Extract(ikm=zero)
master_secret
        ↓ HKDF‑Expand
├─ client_application_traffic_secret_0
└─ server_application_traffic_secret_0
```

## 关键易错点

1. **shared_secret 不能直接用作密钥**
ECDH 输出原始共享值，可能存在高位偏置，必须送入 HKDF‑Extract 做熵混合。
2. transcript hash 范围严格

- handshake_secret 不依赖 transcript hash；
- 但 finished、master_secret、application secret **依赖握手 transcript hash**。

> 
> 很多自实现 TLS1.3 的 bug：漏算某条握手消息进入 transcript。

3. HelloRetryRequest 场景
HRR 之后客户端**重新生成新 KeyShareEntry（新临时私钥）**，整套 ECDH‑HKDF 链路全部重新跑一遍，旧 shared_secret 直接丢弃。
4. PSK 模式
PSK 模式下，`early_secret` 来自 PSK；没有 PSK 就填全零，链路不变。

## Rust 伪代码（极简，仅演示调用链，不可生产）

```rust
// input
let local_eph_sk: &[u8];        // 本端临时私钥
let remote_pub: &[u8];          // KeyShareEntry.key_exchange
let hash_len: usize = 32;
let zero_32 = &[0u8;32];

// step1 ECDH
let shared_secret = x25519_diffie_hellman(local_eph_sk, remote_pub);

// step2 early_secret (no PSK case)
let early_secret = hkdf_extract(zero_32, zero_32);
let derived_early = hkdf_expand(&early_secret, b"derived", hash_len);
let handshake_secret = hkdf_extract(&derived_early, &shared_secret);

// step3 handshake traffic secret
let client_hs_secret = hkdf_expand(&handshake_secret, b"c hs traffic", hash_len);
let server_hs_secret = hkdf_expand(&handshake_secret, b"s hs traffic", hash_len);

// step4 master secret
let derived_hs = hkdf_expand(&handshake_secret, b"derived", hash_len);
let master_secret = hkdf_extract(&derived_hs, zero_32);

let client_app_secret0 = hkdf_expand(&master_secret, b"c ap traffic", hash_len);
let server_app_secret0 = hkdf_expand(&master_secret, b"s ap traffic", hash_len);
```
