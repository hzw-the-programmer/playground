# 概率期望、方差详解

## 一、先区分随机变量

**离散型随机变量**：取值是有限 / 可列个孤立的值（掷骰子：1,2,3,4,5,6）
**连续型随机变量**：取值是区间上连续实数，用概率密度函数\(f(x)\)描述（身高、时间）

---

# 1. 数学期望 \(E(X)\)（均值，加权平均）

> 
> 含义：随机变量**平均取值**，按概率做权重的平均值。

### ✅ 离散型期望

设离散随机变量X，取值\(x_i\)，对应概率\(P(X=x_i)=p_i\)

\(\boldsymbol{E(X)=\sum_{i} x_i\,p_i}\)
约束：\(\sum p_i=1\)

例子：掷一枚公平骰子
\(x=\{1,2,3,4,5,6\},\ p_i=\frac16\)

\(E(X)=\frac16(1+2+3+4+5+6)=\boldsymbol{3.5}\)

### ✅ 连续型期望，概率密度\(f(x)\)

\(\boldsymbol{E(X)=\int_{-\infty}^{+\infty} x\,f(x)\,dx}\)

### 📌 期望重要性质（必考）

1. \(E(c)=c\)，常数的期望等于本身
2. \(E(cX)=c\,E(X)\)，常数可以提出来
3. \(\boldsymbol{E(X+Y)=E(X)+E(Y)}\) **无条件成立！不需要 X,Y 独立！非常关键**
4. \(E(X+c)=E(X)+c\)
5. 若\(X,Y\)**相互独立**：\(\boldsymbol{E(XY)=E(X)\,E(Y)}\)

> 
> ⚠️ 不独立的时候这个等式一般不成立！

> 
> 补充：\(g(X)\)是 X 的函数，随机变量函数的期望
> 离散：\(\displaystyle E[g(X)]=\sum_i g(x_i)p_i\)
> 连续：\(\displaystyle E[g(X)]=\int g(x)f(x)dx\)
> 👉 **不要写成\(g(E(X))\)！一般\(E[g(X)]\neq g(E(X))\)（Jensen 不等式）**

---

# 2. 方差 \(\boldsymbol{D(X)}\) 或者 \(\boldsymbol{Var(X)}\)

> 
> 含义：刻画随机变量**偏离期望值的波动、分散程度**。
> 方差越大，结果越飘忽；方差越小，取值集中在期望附近。

## 定义式（原始定义：离差平方的期望）

\(\boldsymbol{Var(X)=E\big[\,(X-E(X))^2\,\big]}\)

解释：拿每一个随机取值减去均值（偏离），平方消除正负，再取期望，得到平均偏离的平方。

## ✨ 方差常用计算公式（变形公式，做题优先用！）

展开：

\(\begin{aligned}
Var(X) &= E\left[(X-E(X))^2\right] \\
&= E\big[X^2 -2X E(X)+(E(X))^2\big] \\
&= E(X^2)-2E(X)E(X)+(E(X))^2 \\
\boldsymbol{Var(X)} &\boldsymbol{=E(X^2)-\big[E(X)\big]^2}
\end{aligned}\)> 
> 超级重要公式！做题一般先算\(E(X)\)、\(E(X^2)\)再相减。

### 标准差 \(\boldsymbol{\sigma(X)=\sqrt{Var(X)}}\)

方差是平方的单位；标准差还原回原始变量单位，更直观。

### 离散、连续形式写出来

离散：

\(Var(X)=\sum_i \big(x_i-E(X)\big)^2\,p_i\)
连续：

\(Var(X)=\int_{-\infty}^{+\infty} \big(x-E(X)\big)^2 f(x)\,dx\)### 📌方差核心性质（⚠️方差没有线性！注意平方）

1. \(Var(c)=0\)，常数方差为 0（没有波动）
2. \(\boldsymbol{Var(cX)=c^2\,Var(X)}\)！**常数提出来要平方！不是 c！易错点**
3. \(Var(X+c)=Var(X)\)，整体平移随机变量，方差不变；只改变期望。
4. \(\boldsymbol{X,Y}\)相互独立时：

\(Var(X\pm Y)=Var(X)+Var(Y)\)
> 
> ⚠️！不管加减，都是相加！\(Var(X-Y)=Var(X)+Var(Y)\)，不是减！
> 如果**不独立**，需要加上协方差项：

\(Var(X+Y)=Var(X)+Var(Y)+2\,\mathrm{Cov}(X,Y)\)

# 3. 举完整例题（离散）

骰子 X：\(E(X)=3.5\)
先求\(E(X^2)=\frac16(1^2+2^2+\dots+6^2)\)

\(E(X^2)=\frac{91}{6}\approx15.1667\)
\(Var(X)=E(X^2)-[E(X)]^2
=\frac{91}{6}-3.5^2=\boldsymbol{\frac{35}{12}\approx2.9167}\)
标准差\(\sigma=\sqrt{\frac{35}{12}}\approx1.708\)

# 4. 常见分布的期望方差速查表

表格

| 分布              | 记号                | 期望 E (X)        | 方差 Var (X)           |
| ----------------- | ------------------- | ----------------- | ---------------------- |
| 0‑1 分布 (伯努利) | \(B(1,p)\)          | p                 | \(p(1-p)\)             |
| 二项分布          | \(B(n,p)\)          | np                | \(np(1-p)\)            |
| 泊松分布          | \(P(\lambda)\)      | \(\lambda\)       | \(\lambda\)            |
| 均匀分布 (连续)   | \(U[a,b]\)          | \(\frac{a+b}{2}\) | \(\frac{(b-a)^2}{12}\) |
| 指数分布          | \(Exp(\lambda)\)    | \(\frac1\lambda\) | \(\frac1{\lambda^2}\)  |
| 正态分布          | \(N(\mu,\sigma^2)\) | \(\mu\)           | \(\sigma^2\)           |

> 
> 注意正态记号\(N(\boldsymbol{\mu,\sigma^2})\)第二个参数直接就是方差，不是标准差！

# 5. 易错点总结

1. ✅期望无条件可加：\(E(X+Y)=E(X)+E(Y)\)，**不需要独立**
2. ❌方差可加**必须独立**；\(Var(cX)=c^2Var(X)\)，系数平方！
3. ❌\(E(X^2)\neq [E(X)]^2\)，二者之差就是方差！
4. ❌\(Var(X-Y)\neq Var(X)-Var(Y)\)；独立时依然是\(Var(X)+Var(Y)\)
5. \(E[g(X)]\neq g(E(X))\)，函数不能随便拿到期望外面（Jensen 不等式）

## 补充 Jensen 不等式（拓展）

若g是凸函数，则 \(g(E(X)) \le E[g(X)]\)；凹函数反向。
比如\(g(x)=x^2\)是凸，\((E(X))^2\le E(X^2)\)，所以方差恒大于等于 0。
