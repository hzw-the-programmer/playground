# 中国信保（中国出口信用保险公司，Sinosure）

**定位**：2001‑12‑18 成立，**国家出资的国有政策性保险公司**，中央管理金融企业，国内唯一政策性出口信用保险机构。
核心使命：**履行政策性职能，服务高水平对外开放**，帮外贸、海外投资企业对冲海外商业风险与国别政治风险，属于政策性金融工具，不以商业盈利为首要目标。

## 核心业务板块

1. **短期出口信用保险（最常用）**
对应一般货物贸易出口（收汇账期 1 年以内）。保障海外买家拖欠货款、拒收货物、破产，以及进口国政治风险；中小微外贸企业主力险种。投保后企业可拿保单向银行做**保单融资**，解决应收账款占用资金问题。
2. **中长期出口信用保险**
针对大型机电设备、海外工程总承包、成套设备出口，账期 1‑15 年；服务基建、新能源出海大项目。
3. **海外投资保险（境外投资险）**
中国企业出海投资建厂、并购，承保东道国**征收、汇兑限制、战争暴乱、政府违约**等政治风险，是企业 “走出去” 核心风险工具。
4. **国内贸易信用保险**
国内企业之间赊销交易，防范下游买方拖欠坏账，服务内外贸一体化。
5. **进口信用保险**
保护国内进口商，防范海外供应商违约风险。
6. **配套服务**
   - 资信调查：全球企业、国别风险数据库，做买家资信评估、国别风险评级；
   - 担保 / 保函、应收账款追偿、再保险；
   - 数字化工具：**信步天下 APP、信保通**，风险查询、线上投保理赔；客服热线：**95387**。

## 两类主要风险保障

- **商业风险**：海外买方破产、拖欠货款、拒收货物；
- **政治 / 国别风险**：外汇管制、战争内乱、征收国有化、进口禁令、政府违约。

> 
> 注意：不承保货物质量纠纷、企业自身经营亏损；只保**信用类损失（买家不付钱）**。

## 现实作用

1. **风险兜底**：海外买家赖账、国别动荡，企业可获得赔款，降低出海不确定性；
2. **融资增信**：信用保单质押给银行，外贸企业更容易拿到出口信贷，解决中小外贸企业缺抵押的痛点；
3. **引导市场布局**：通过承保限额、风险提示，引导企业规避高风险国别，拓展新兴市场；
4. **支持重点产业**：新能源、工程机械、电子信息、生物医药、整车等产业链出海，是 “一带一路” 项目关键金融配套工具。

## 关键数据概览

- 业务规模长期位居全球官方出口信用保险机构首位；
- 截至 2025 年底，累计支持贸易投资规模超**10 万亿美元**，服务超 40 万家企业，累计赔款受偿超 279 亿美元；
- 大量中小微外贸企业纳入普惠保障，提升我国出口信用保险渗透率。

## 和商业保险公司核心区别

表格

| 项目     | 中国信保                                       | 普通商业财险 / 信用险                |
| -------- | ---------------------------------------------- | ------------------------------------ |
| 属性     | 政策性金融机构，国家背景                       | 商业市场化机构，追求盈利             |
| 承保导向 | 国家外贸、对外投资战略，愿意承接高国别风险项目 | 商业回报优先，高风险国别买家通常拒保 |
| 客户     | 大型出海项目、中小微外贸、境外投资企业         | 国内赊销、部分出口业务               |

### 常见认知补充

1. 不是所有出口都强制投保；企业自主选择投保，部分地方政府会对中小微企业信保保费给予财政补贴；
2. 主要解决**“买家不付钱”**，不等于保证订单一定赚钱；贸易合同本身纠纷不在保障内；
3. 很多出海基建、光伏电站、海外工厂投资项目，银行放贷前提就是要求配置中国信保海外投资保险。
