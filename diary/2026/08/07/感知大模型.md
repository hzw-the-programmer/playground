# 机器人：感知大模型 & 运动控制大模型

传统机器人：感知→规划→控制，模块拆开，手工写大量规则；

大模型范式：用 VLM/VLA（视觉‑语言‑动作）把感知、理解、运动策略融合，端到端从传感器输入输出机器人动作。

# 一、感知大模型（机器人视觉‑语言模型 VLM）

职责：看懂物理世界，回答 “环境里有什么、在哪、什么状态”

输入：相机图像、深度图、激光、触觉、IMU、自然语言指令

输出：物体识别、6D 位姿、语义分割、场景图、三维语义地图、语言理解，不输出电机指令。

## 核心能力

1. 开放世界识别：识别没训练过的物体（GDINO、SAM）

2. 多模态对齐：把自然语言 “拿红色杯子” 映射到图像上对应物体

3. 多传感器融合：RGB‑D、激光、触觉融合，做 SLAM、状态估计

3. 场景推理：理解空间关系、物体状态（杯子倒了、门半开）

## 代表模型 / 组件

- PaLM‑E：LLM 接入图像，语言 + 视觉做高层任务推理

- DINOv2：自监督视觉特征提取

- GDINO 二、运动控制大模型（VLA 视觉‑语言‑动作模型）
职责：把 “看懂的环境 + 人的指令” 变成机器人真实关节动作，回答 “机器人该怎么动”
输入：图像、机器人关节状态、语言指令；
输出：关节角度、末端位姿、力矩序列，直接驱动电机。
VLA = 感知编码 + 策略头，把视觉、语言、动作统一 token，Transformer 做序列建模。
主流技术路线 SAM：开放世界检测分割

- CLIPort：语言引导抓取感知，输出可抓取热力图

##岗位关键词

实例分割、6D 位姿估计、手眼标定、VLM 微调、LoRA、多传感器融合、SLAM、语义建图、点云处理（PCL）

> ⚠️感知大模型只管看懂环境；看懂之后 “手怎么动” 交给运动控制大模型。

# 二、运动控制大模型（VLA 视觉‑语言‑动作模型）

职责：把 “看懂的环境 + 人的指令” 变成机器人真实关节动作，回答 “机器人该怎么动”

输入：图像、机器人关节状态、语言指令；

输出：关节角度、末端位姿、力矩序列，直接驱动电机。

> VLA = 感知编码 + 策略头，把视觉、语言、动作统一 token，Transformer 做序列建模。

## 主流技术路线

路线	原理	代表模型	特点
动作 Token 化	把连续动作离散成 token，像文本一样生成	RT‑2、OpenVLA	复用 LLM 架构；精度受离散 bin 限制
行为克隆 直接回归	网络直接回归关节 / 末端连续值	ACT	简单；容易平均化，多解场景效果差
扩散策略 Diffusion Policy	噪声逐步去噪生成动作序列	Octo	擅长灵巧操作；推理步数多、速度慢
Flow‑Matching	流匹配生成连续动作块	π0/π0.5	高频灵巧人形控制，性能强，现在主流方向

## 里程碑模型

1. RT‑2（Google）：真正 VLA 开山，VLM 微调输出动作 token，互联网知识迁移到机器人

2. Octo：通用机器人策略，一套模型适配多种机械臂

3. π0 系列：人形灵巧手、全身控制，Flow‑Matching 范式

4. NVIDIA GR00T：人形机器人基础控制大模型，面向全身运动、操作任务

## 岗位关键词

模仿学习、行为克隆、Diffusion Policy、Flow‑Matching、Action Chunking、Sim2Real、Isaac Sim / MuJoCo、机器人轨迹数据集、真机部署闭环调优。

# 三、感知大模型 vs 运动控制大模型简明对比

维度	感知大模型 (VLM)	运动控制大模型 (VLA)
核心问题	环境是什么？物体在哪？	机器人该怎么动？
输出	语义、位姿、特征、文本	关节角度、力矩、动作序列
是否直接控电机	❌不直接控制	✅输出可执行控制量
实时性压力	中等，几百 ms 可接受	极高，人形需要 20‑200Hz 闭环
失败后果	看错物体，任务失败	看错 + 输出错误动作，会撞机、损坏硬件
训练数据	图像、视频、标注	机器人真实轨迹数据（图像 + 状态 + 动作成对）

# 四、完整闭环链路（具身智能）

```text
相机/传感器 →【感知大模型VLM】理解场景 + 语言指令
　　　　　　　↓
【VLA运动控制大模型】生成动作序列
　　　　　　　↓
底层控制器（PID、动力学）→电机执行
　　　　　　　↓
观测新图像，循环闭环
```

> 工程上有两种架构：
> 1. 解耦架构：独立 VLM 输出感知结果，喂给控制策略；可控好调试，传统工业机器人常用。
> 2. 端到端 VLA：图像直接进模型输出动作；泛化强，但黑盒，真机调试难度大，人形机器人现在重点研究方向。

# 五、和前面 “机器人开发应用工程师” 的岗位差异

感知 / 运动控制算法工程师（研发岗）：硕士起步，做模型设计、训练、微调、数据集、仿真训练，产出模型权重；年薪 50‑100 万，门槛高，重论文、算法、深度学习、机器人理论。

机器人开发应用工程师（落地交付岗）：拿已经训练好的感知 / 控制模型，做场景适配、调试、二次开发、产线落地；本科可入行，年薪 20‑60 万，重 ROS2、现场调试、项目经验。

> 简单记：算法工程师造大脑，应用工程师把大脑装到机器人身上，教会机器人干活。
