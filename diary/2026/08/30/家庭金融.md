# 家庭金融

> 
> 家庭金融（Household Finance）：把一个家庭视作微型 “资产负债表主体”，研究家庭如何做**收入、消费、储蓄、投资、负债、保险、养老、传承**的整套决策，目标：平滑一生消费、对冲风险、实现家庭财富稳健增值。

## 一、家庭核心资产负债表（极简模板）

### 资产（左边）

1. **流动性资产**：现金、货币基金、活期存款，用于应急，一般建议：**3‑6 个月家庭总开支**
2. **固收类资产**：定期存款、国债、债券基金、银行理财
3. **权益类资产**：股票、股票基金、指数 ETF、股权
4. **实物资产**：自住房产、投资房产、车辆、黄金
5. **保障类资产**：各类保险保单现金价值、企业年金、养老金

### 负债（右边）

- 良性负债：房贷、低息经营贷（利率低、资产增值＞负债成本）
- 恶性负债：信用卡分期、消费贷、网贷（高利息，尽量清零）

**家庭净资产 = 总资产 − 总负债**

## 二、家庭金融五大核心目标

1. **风险兜底：保险优先于投资**
先把家庭风险缺口补上，再做理财。

- 家庭经济支柱优先配置：重疾、医疗、寿险、意外险；老人侧重医疗 / 意外；孩子优先医疗意外。

> 
> 原则：不要用理财去对抗疾病死亡风险。

2. **建立应急金**
3‑6 个月家庭刚性支出，放随取的流动性工具，不追求高收益，求稳。
3. **生命周期的资产配置**

表格

| 人生阶段         | 核心矛盾                 | 配置思路                               |
| ---------------- | ------------------------ | -------------------------------------- |
| 青年组建家庭     | 收入上涨、房贷压力       | 高权益打底，控制负债比例               |
| 中年上有老下有小 | 教育、养老、健康三重压力 | 股债均衡，逐步降低风险敞口             |
| 退休阶段         | 现金流优先，抗通胀       | 固收为主，少量权益对抗通胀，重在现金流 |

> 
> 经典经验法则：**权益占比 ≈ 100 − 家庭主要成员年龄**，仅参考，需要结合风险承受力调整。

4. **负债管理**

- 家庭总月供建议不超过家庭税后月收入**40%**；超过 50% 属于高负债风险区。
- 高息负债优先偿还，低息负债可以保留，把钱拿去做更高确定性投资。

5. **长期目标拆解：子女教育、养老、财富传承**

- 教育金、养老金属于**长周期目标**，适合定投指数基金、年金等工具，避免短期投机。
- 传承：遗嘱、保险、家庭资产隔离，避免婚姻、债务带来资产流失。

## 三、几个经典家庭金融指标（可以直接自测）

1. **储蓄率 =（税后总收入 − 总消费）÷ 税后总收入**

> 
> 健康家庭建议储蓄率≥20%，年轻家庭越高越好。

2. **债务收入比 = 年度总债务还款 ÷ 家庭税后年收入**，建议＜40%
3. **流动性比率 = 流动性资产 ÷ 每月家庭支出**，≥3 才算安全。
4. **保险保障倍数：寿险保额 ≥ 家庭年收入 ×（8‑10 倍）**，覆盖家人生活、房贷。

## 四、常见家庭金融误区

1. 把房产当成唯一资产：房产占总资产过高，流动性枯竭，遇到失业、疾病容易被动。
2. 本末倒置：高风险投资一把梭，却不配置保险，一次黑天鹅直接击穿家底。
3. 混淆 “消费” 和 “投资”：豪车、奢侈品属于消费，不会产生现金流。
4. 盲目跟风高收益产品：家庭第一要义是**生存安全**，其次才是收益。
5. 家庭资产不分层：全部钱放同一个池子，应急钱、教育金、养老钱混在一起。

## 五、家庭资产三层金字塔

1. **底层安全垫（50‑70%）**：现金、存款、国债、保险，保证家庭活下去。
2. **中层增值层（20‑40%）**：指数基金、股票、优质权益，博取长期收益。
3. **上层进取层（0‑10%）**：小众标的、个股、另类投资，亏完也不影响家庭生活。

> 
> 信息仅供参考，不构成投资建议。
