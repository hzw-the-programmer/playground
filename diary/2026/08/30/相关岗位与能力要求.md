# 家庭金融｜相关岗位与能力要求

分为**业务实操岗、研究分析岗、数字化产品岗、学术研究岗**四大类，同时给出核心能力矩阵、证书、入行门槛。

## 一、主流岗位清单

### 1. 业务实操类（面向 C 端家庭客户，行业最大体量）

1）**银行零售 / 理财经理、私人银行顾问**

- 工作内容：家庭财务诊断、资产负债梳理、应急金‑保险‑投资‑养老综合规划；基金、理财、年金、信托配置；高净值家庭兼顾婚姻财产、家族信托、财富传承。
- 服务对象：普通中产、高净值家庭。

2）**券商买方投顾、财富顾问**

- 工作内容：以资产配置为核心，基金 ETF 组合、目标日期 FOF、家庭投资账户管理；投资者陪伴、定期再平衡；从卖产品转向按 AUM 收费的顾问模式。

3）**保险养老规划师（家庭风险管理方向）**

- 工作内容：家庭风险缺口测算，医疗险 / 重疾 / 寿险 / 年金、个人养老金规划；重点做家庭现金流、失能、长寿风险对冲。

4）**轻量化家办顾问（普惠家族办公室）**

- 工作内容：中产‑小高净值家庭，金融 + 法律协同；债务隔离、遗嘱、保险金信托、婚姻资产保护、代际传承。

### 2. 研究分析岗（机构后台，不直接对接客户）

1）**财富研究 / 家庭金融研究员**

- 工作内容：跟踪中国家庭资产负债变化、居民杠杆、储蓄行为、房产与金融资产迁移；输出家庭金融报告、资产配置策略、养老金融研究；为前端顾问输出工具、方法论。

2）**消费金融 / 居民信贷风控**

- 工作内容：家庭负债行为研究，识别家庭债务风险，评估家庭偿债能力；研究提前还贷、居民杠杆率、消费信贷行为。

### 3. 数字化 & 产品岗

1）**财富产品经理（家庭金融方向）**

- 工作内容：设计面向家庭的工具：家庭资产负债表工具、养老计算器、智能投顾、目标日期产品；把家庭金融理论转化为可使用的线上产品。

2）**AI 投顾算法 / 策略岗**

- 工作内容：家庭场景下的资产配置算法、生命周期模型、蒙特卡洛家庭现金流模拟。

### 4. 学术方向（高校、智库、金融研究院）

- 高校金融学教师、博士后；社科院、金融机构研究院研究员。
- 研究议题：家庭资产选择、房产与家庭负债、消费行为、行为家庭金融、养老第三支柱。

## 二、通用核心能力要求

### 🔹专业知识

1. **家庭财务底层框架**：家庭资产负债表、收支表；储蓄率、债务收入比、流动性比率；生命周期消费理论；货币时间价值；现金流测算、情景模拟（失业、疾病、长寿）。
2. **全品类金融产品认知**：存款、固收、公募 ETF、FOF、年金保险、信托、个人养老金，理解各类工具适合什么样的家庭阶段。
3. **风险管理与保险规划**：风险缺口测算，区分保障型与储蓄型保险。
4. **交叉知识**：基础婚姻法、继承法、信托基础；个人税务常识；行为金融学（理解家庭非理性投资行为）。
5. **宏观背景**：利率周期、人口老龄化、居民资产从房产向金融资产迁移的大趋势。

### 🔹工具能力

1. Excel：家庭财务建模、现金流测算、情景模拟、资产配置回测。
2. 加分：Python，做居民微观数据分析、蒙特卡洛模拟。
3. 读懂微观调研数据库：CHFS 中国家庭金融调查数据。

### 🔹软能力

1. 客户需求挖掘：区分客户口头诉求和家庭真实财务痛点；区分情绪诉求和客观财务目标。
2. 复杂概念通俗表达：把资产负债、久期、长寿风险翻译成普通家庭听得懂的语言。
3. 合规意识：适当性管理，区分投资建议与客观科普，不承诺收益。

## 三、常用证书（优先级从高到低）

1. **CFP / AFP（国际金融理财师）**：最贴合家庭综合理财规划，完整覆盖家庭收支、保险、投资、养老、传承，银行私行非常看重。
2. **CFA**：侧重投资与资产配置，适合投顾、研究岗；对家庭法律税务部分覆盖较少。
3. **CHFP 理财规划师**：国内本土理财规划证书。
4. 必备基础从业：基金从业、证券从业、保险从业。

> 
> 证书是知识底座，不能替代实战；真正核心是**家庭资产负债表思维 + 生命周期视角**。

## 四、两类职业路径

### 路径 A：业务顾问路线（面向客户）

理财经理 → AFP/CFP 系统学习 → 中产家庭综合规划顾问 → 私人银行 / 轻量化家办顾问。

> 
> 核心变化：从推销产品，变成诊断家庭整体财务问题，输出综合解决方案。

### 路径 B：研究 / 产品路线（后台）

金融 / 经济硕士，掌握微观家庭数据；熟悉 CHFS 等调研数据库；做家庭金融研究；输出报告、工具、产品方案。

## 五、现实职业痛点

1. 国内绝大多数财富岗位仍带有销售考核压力，纯粹中立的付费家庭规划岗位供给还比较少。
2. 复合型人才缺口大：懂金融，又懂家庭法律、税务、养老的人不多。
3. 行业处于转型期：旧模式靠人脉存款；新模式靠家庭财务专业能力，新旧模式并存。
