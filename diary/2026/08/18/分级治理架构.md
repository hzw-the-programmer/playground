# 以股东会、董事会及其专门委员会、经营管理层为核心的分级治理架构

该架构是现代公司法人治理的标准层级结构，遵循**所有权 — 决策权 — 监督权 — 执行权**分离制衡逻辑，自上而下分级授权、权责边界清晰，实现股东所有、董事会决策、管理层执行。

## 一、层级整体逻辑

> 
> 股东会（最高权力机构）→董事会（决策机构，下设专门委员会）→经营管理层（执行机构）
> 监事会为监督配套机构，对股东会负责，独立监督董事会、管理层履职。

### 1. 股东会（股东大会）—— 所有权、最高权力机构

**定位**：公司所有者代表，全体股东行使所有者权利，是治理架构的源头。
主要职权：

1. 决定公司经营方针、投资计划；
2. 选举、更换董事、监事，决定董事监事报酬；
3. 审议批准董事会、监事会报告；
4. 审议批准财务预算、决算、利润分配、亏损弥补方案；
5. 修改公司章程、增减注册资本、合并分立解散、重大对外担保等重大事项。
**向下关系**：选举产生董事会、监事会，对董事会下达授权，董事会向股东会负责并报告工作。

### 2. 董事会 —— 战略决策机构

**定位**：受股东会委托，行使公司经营决策权，对股东会负责，是治理的核心枢纽。
主要职权：

1. 执行股东会决议；
2. 制定公司经营计划、投资方案、财务预决算、利润分配等方案提交股东会审议；
3. 聘任 / 解聘总经理、高管，决定高管薪酬考核；
4. 设置董事会专门委员会；
5. 制定内部管理制度，把控重大风险。

> 
> 董事会下设**专门委员会**，属于董事会内设工作机构，不直接对外决策，为董事会提供专业前置审议、咨询意见，议案经委员会审议后提交董事会表决。
> 常见专门委员会：

- **战略委员会**：研究中长期发展战略、重大投融资、并购重组；
- **审计委员会**：财务审核、内控建设、内审管理、外部审计选聘，风险合规核查；
- **薪酬与考核委员会**：董事、高管薪酬方案、绩效考核方案；
- **提名委员会**：董事、高级管理人员人选遴选、资格审查；
部分企业增设风险管理委员会、关联交易委员会等。

专门委员会由董事组成，审计、薪酬考核委员会要求独立董事占多数并担任主任。

### 3. 经营管理层（经理层）—— 执行机构

**定位**：由总经理牵头，落实董事会决议，负责日常生产经营管理，向董事会负责。
组成：总经理、副总经理、财务负责人及其他高级管理人员。
主要职权：

1. 组织实施董事会决议；
2. 主持日常经营管理，组织实施经营计划、投资方案；
3. 拟订内部机构设置方案、基本管理制度；
4. 提请董事会聘任或解聘副职高管，任免中层管理人员；
5. 在董事会授权范围内开展经营活动。

> 
> 权责边界：经理层只有执行权，重大事项不得越权决策，重大事项必须报董事会 / 股东会审批。

### 4. 监事会（监督机构，配套）

定位：对股东会负责，独立监督，不参与经营决策。
职权：监督董事、高管履职，检查公司财务，制止董事高管损害公司利益行为。

## 二、分级治理运行流程

1. **股东会**：审议重大事项，选举董事监事，授权董事会开展经营；
2. **董事会专门委员会**：对专项事项做前置调研、专业审查，形成专项意见提交董事会；
3. **董事会会议**：审议委员会议案、经理层提交方案，做出经营决策，下达给经理层执行；
4. **经营管理层**：落地执行董事会决议，开展日常经营，定期向董事会汇报经营情况；
5. **监事会**：全程监督董事会、经理层履职，向股东会报告监督情况。

## 三、各主体权责边界要点

表格

| 机构             | 核心权力                   | 责任对象 | 禁止越权                           |
| ---------------- | -------------------------- | -------- | ---------------------------------- |
| 股东会           | 重大事项审批、选举董事监事 | 全体股东 | 不干预日常经营，不直接指挥管理层   |
| 董事会           | 战略经营决策               | 股东会   | 不直接从事日常业务执行             |
| 董事会专门委员会 | 专业调研、前置审议         | 董事会   | 无独立决策权，不能对外发文拍板     |
| 经营管理层       | 日常经营执行               | 董事会   | 不得绕过董事会做重大投资、人事决策 |

## 四、治理架构核心原则

1. **分权制衡**：所有权、决策权、执行权相互分离，既分工又制衡；
2. **逐级授权**：股东会授权董事会，董事会授权经理层，权责匹配、授权留痕；
3. **专门委员会专业支撑**：弥补董事会专业短板，提升重大决策科学性；
4. **层层报告**：董事会向股东会报告，经理层向董事会报告，监事会向股东会报告。
