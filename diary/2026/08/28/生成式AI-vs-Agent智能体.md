# 生成式 AI vs Agent 智能体

一句话本质区别：
**生成式 AI：人提问 → AI 输出内容，被动响应，只动脑不做事；Agent 智能体：人给目标 → AI 自己拆步骤、调用工具、循环执行、拿到结果，主动闭环做事**。

> 
> 注意：**Agent 并不是取代大模型，Agent 把生成式大模型当作自己的 “大脑”**，大模型负责思考，Agent 增加记忆、规划、工具调用、反馈循环整套外壳。

## 通俗例子对比

需求：帮我调研 3 家半导体公司，整理一份对比报告，把报告发送到我的邮箱。

1. **生成式 AI（普通大模型）**
你需要：“请调研 A/B/C 三家半导体公司，整理对比报告”
AI 输出一份文本报告。**到此结束**。

- 不会自己上网查最新财报；不会自动打开邮箱发送；如果信息不全，需要你再次发指令让它补充。
- 模式：**一问一答，输出即结束**。

2. **Agent 智能体**
你只需要一句话目标：“调研 3 家半导体公司，整理对比报告，发送到我的邮箱”
Agent 自动执行完整闭环：
1）规划：需要搜索财报、股价、业务；
2）调用搜索工具拉取最新公开数据；
3）发现某家缺少 2026 半年报 → 再次检索；
4）调用大模型生成对比文档；
5）调用邮件 API 把文档发出；
6）校验发送状态，把最终结果通知你。
中间出错会重试，不需要你一步步指挥。

## 核心维度对照表

表格

| 对比项       | 生成式 AI（Generative AI）                       | Agent 智能体（Agentic AI）                                                               |
| ------------ | ------------------------------------------------ | ---------------------------------------------------------------------------------------- |
| 驱动模式     | **被动响应式**：收到 Prompt 才输出，无输入就停止 | **目标驱动主动式**：给定总目标，自主跑多轮流程                                           |
| 工作流程     | 单次：输入→生成输出，流程断开                    | 闭环循环：**感知→规划→工具调用→执行→反思修正**                                           |
| 记忆         | 只有当前对话上下文，无长期任务记忆               | 具备短期上下文 + 长期记忆，记住任务进度                                                  |
| 工具调用     | 有限，大多需要人明确指令才调用                   | **自主决定什么时候调用什么工具**（搜索、数据库、API、代码执行）                          |
| 用户工作量   | 高：人需要拆任务、分步提问、校验结果             | 低：只需要高层目标，中间步骤 AI 自己处理                                                 |
| 输出产物     | 文本、图片、代码等**内容**                       | 可以是内容，也可以是真实世界动作：发邮件、查数据库、下单、系统操作                       |
| 硬件负载特点 | 主要消耗 GPU 做 Token 生成                       | **GPU+CPU 双重压力**：大量调度、工具调用、循环推理，这正是 Vera Rubin 平台重点解决的场景 |

## 回到黄仁勋说的 AI 转折点

1. 过去是**生成式 AI 时代**：主要负载是 “一问一答生成内容”，瓶颈在 GPU 算力；
2. Agent 时代：大量多轮工具调用、任务规划、循环反思，**CPU 调度压力暴涨，GPU 经常等待 CPU，造成算力浪费**，所以英伟达推出 Vera Rubin 平台，自研 Vera CPU 专门处理 Agent 的调度负载，Rubin GPU 负责推理，整套机架面向智能体工作流做全栈优化。

## 容易混淆的点

1. “会调用插件的 ChatGPT ≠完整 Agent”
普通插件需要你明确说 “调用 XX 工具”；真正 Agent 是**自己判断要不要调用工具、调用几次、失败了重试**。
2. Agent 离不开生成式大模型：大模型提供理解、推理、写作；Agent 是在大模型之上新增任务调度、记忆、外部交互的系统框架。
