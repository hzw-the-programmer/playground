# 《伊利亚特》

## 基础信息

- 作者：荷马（古希腊）
- 体裁：长篇英雄史诗，共 24 卷，约一万五千行
- 姊妹篇：**《奥德赛》**

> 
> 《伊利亚特》写**特洛伊战争第十年**；《奥德赛》写战争结束后英雄返乡。
> 注意：本书**并没有写木马计、特洛伊城灭亡**，故事在赫克托尔下葬就结束。

书名直译：《伊利昂纪》，伊利昂就是特洛伊城。

## 故事背景

特洛伊战争已经打了九年，希腊联军（阿开亚人）围困特洛伊。史诗截取**第十年短短几十天**的冲突，不是完整战争全过程。

## 核心起因：阿喀琉斯的愤怒（全书开篇第一句）

> 
> “歌唱吧，女神！歌唱阿喀琉斯的愤怒。”

1. 联军统帅**阿伽门农**抢走阿喀琉斯的战利品女俘，侮辱阿喀琉斯。
2. 希腊第一勇士**阿喀琉斯**怒而罢战，拒绝上战场。
3. 失去最强战力，希腊军队被特洛伊人打得节节败退，死伤惨重。

## 主要人物

### 希腊联军

1. **阿喀琉斯**：半人半神，全军最强战士。性格：骄傲、易怒、重情义，也残暴。母亲是海洋女神忒提斯。
2. **阿伽门农**：联军总司令，迈锡尼国王，傲慢看重权威。
3. **帕特罗克洛斯**：阿喀琉斯最亲密挚友。
4. **奥德修斯**：智谋代表，擅长劝说、谋略。

### 特洛伊方

1. **赫克托尔**：特洛伊大王子，特洛伊第一英雄。顾家、克制、有责任感，悲剧英雄。明明预知城邦将毁灭，依然为国赴死。
2. **普里阿摩斯**：特洛伊年迈国王。
3. **安德洛玛刻**：赫克托尔的妻子，预见丈夫战死，充满悲剧感。

### 神明

众神各帮一方：赫拉、雅典娜站希腊；阿佛洛狄忒站特洛伊；宙斯居中权衡。神明会直接干预战场，操纵凡人命运。

## 关键情节脉络

1. 阿喀琉斯受辱，拒绝出战，希腊人惨败。阿伽门农派人送重礼求和，阿喀琉斯依然拒绝。
2. 战局危急，好友帕特罗克洛斯穿上阿喀琉斯的铠甲，假扮他出战，击退敌军，却被**赫克托尔斩杀**。
3. 挚友之死彻底击溃阿喀琉斯。放下和阿伽门农的恩怨，重新奔赴战场，燃起复仇怒火。
4. 战场上阿喀琉斯狂暴追杀，决战杀死赫克托尔，还凌辱拖拽赫克托尔的尸体。
5. 深夜，老国王普里阿摩斯孤身潜入希腊军营，跪在阿喀琉斯面前，哀求赎回儿子的遗体。
6. 阿喀琉斯想起自己年老的父亲，心生怜悯，归还赫克托尔尸体。
7. 史诗结尾：特洛伊为赫克托尔举行盛大葬礼。**到此全书结束**。

> 
> 木马计、城破毁灭属于后世其他传说，不属于《伊利亚特》文本。

## 核心主题

1. **英雄的荣耀与宿命**：英雄追求名声荣光，但逃不开死亡命运。阿喀琉斯有两个命运：长寿平庸，或者短暂一生赢得不朽威名，他选择后者。
2. **战争的双重面貌**：歌颂英雄勇武，同时毫不回避战争残酷、死亡、离别、家庭破碎。赫克托尔与妻儿诀别段落是全书最悲情片段。
3. **愤怒与克制**：阿喀琉斯的愤怒带来毁灭；最后的怜悯，是人性的回归。
4. **神意与凡人**：神明可以左右战局，但凡人依旧拥有尊严、情感。

## 和《奥德赛》对比简表

表格

|      | 《伊利亚特》         | 《奥德赛》               |
| ---- | -------------------- | ------------------------ |
| 聚焦 | 战争、沙场、荣誉     | 漂泊、历险、归乡、家庭   |
| 主角 | 阿喀琉斯（武力英雄） | 奥德修斯（智谋隐忍英雄） |
| 时间 | 特洛伊战争第十年     | 战争结束之后十年         |
| 基调 | 悲壮、惨烈           | 冒险、救赎               |

## 文学地位

西方文学的源头。后世无数悲剧、诗歌、小说都从中取材。
词语引申：**阿喀琉斯之踵**—— 唯一弱点。阿喀琉斯母亲当年捏住他脚踝浸泡冥河，全身刀枪不入，唯独脚踝没有沾水，最后被帕里斯射中脚踝战死。
