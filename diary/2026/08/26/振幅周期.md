# 振幅、周期、普通频率、角频率、相位 完整详解

以标准简谐振动 / 正弦信号为模型：

x(t) = A * cos(ωt + φ)
这是最通用表达式，音频、振动、交流电、电磁波全部用这套概念。

> 
> t：时间，单位 s（秒）

## 1. 振幅 A

**物理含义：振动偏离平衡位置的最大幅度。**

- 单位：和信号本体一致。位移就是米；电压就是伏特；声音就是声压。
- A 越大，振动越强。
- cos 的取值范围 [-1, 1]，所以信号取值范围：[-A, +A]
- 振幅只描述**大小强弱，不关心快慢、什么时候开始**。

例子：x(t)=5 * cos(...)，振幅 A = 5，信号最大到 +5，最小到 -5。

---

## 2. 周期 T

**周期：完成一次完整震荡所需要的时间。**
符号：T，单位：**秒 (s)**。

- 经过 T 秒，波形完全重复一遍。
- 周期越大，振动越慢；周期越小，振动越快。

例：钟摆来回摆动一次耗时 2 秒，则 T = 2s。

### 周期和普通频率互为倒数

f = 1 / T, T = 1 / f

---

## 3. 普通频率 f（频率，Frequency）

**含义：每一秒钟，一共振动多少个完整周期。**
符号：f，单位：**赫兹 Hz**，1Hz = 1次/秒。

- f = 100Hz：1 秒钟震荡 100 圈。
- f 越大，振动越快，音调越高。

> 
> 生活中说的 440Hz 钢琴 A 音，就是普通频率 f。

> 
> ⚠️重点区分：

- T：**一次循环要几秒**
- f：**一秒有多少次循环**

举例：
周期 T = 0.02s，那么 f = 1 / 0.02 = 50Hz。

---

## 4. 角频率 ω（Omega，角速度）

> 
> 很多初学者最容易混淆的量。

物理图像：想象一个单位圆上一个点**匀速旋转**。

- f：每秒转多少圈（圈 / 秒，Hz）
- ω：每秒转过多少**弧度**（rad/s，弧度每秒）

一圈完整圆周是 2π 弧度。
每一秒转 f 圈，总转过的弧度：

ω = 2πf
又因为 f = 1 / T，所以

ω = 2π / T

表格

| 量  | 含义         | 单位  |
| --- | ------------ | ----- |
| f   | 每秒多少圈   | Hz    |
| ω   | 每秒多少弧度 | rad/s |

例子：
f = 50Hz

ω = 2π * 50 = 100π ≈ 314.16 rad/s

> 
> 傅里叶变换公式里面用的全部是角频率 ω，不是 f！
> 
> 
> F(w) = ∫ f(t)e^{-jwt} dt

> 
> e^{jwt} 代表复平面上，以角速度 w 逆时针旋转的单位向量。

### 小结换算公式（务必背熟）

w = 2πf = 2π/T,
f = 1/T = w/2π,
T = 1/f = 2π/w
---

## 5. 相位、初相位 φ

表达式：x(t) = A * cos(ωt + φ)

### ① 瞬时相位（总相位）：θ(t) = ωt + φ

θ(t)：随时间不断增加的角度（弧度）。
每过 dt，相位增加 ω * dt，对应旋转向量转过角度。

### ② 初相位 φ（相位偏移）

t = 0 时刻的瞬时相位：θ(0) = φ。

> 
> **初相决定波形在时间轴上整体往左 / 右平移多少，不改变振幅、快慢。**

单位：弧度 rad，也可以用角度 °。

举例对比：

1. x1(t) = cos(ωt)，φ = 0。
t = 0，x1(0) = cos0 = 1，起点在最大值。
2. x2(t) = cos(ωt + π/2)，φ = π/2。
t = 0，x2(0) = cos(π/2) = 0。
波形整体**向左移动 1/4 周期**。

> 
> 初相 φ > 0：波形向左挪；
> 初相 φ < 0：波形向右挪。

### 相位差

两个同频率信号之间相位的差值 Δφ。

x1 = A1 * cos(ωt + φ1)
x2 = A2 * cos(ωt + φ2)

相位差：Δφ = φ1 - φ2

- Δφ = 0：同相，两个波形完全对齐
- Δφ = π：反相，一个波峰对应另一个波谷
- Δφ = π/2：正交，相差四分之一周期

> 
> ⚠️只有**频率相同**，相位差才有固定意义；频率不同，相位差随时间不断变化。

# 形象化统一比喻：圆周旋转模型（非常关键）

想象一个圆盘绕圆心匀速转动：

1. **振幅 A**：圆盘上点到圆心的距离（半径），投影最大高度
2. **普通频率 f**：圆盘每秒转多少圈
3. **角频率 ω**：圆盘每秒转过多少弧度
4. **周期 T**：圆盘完整转一圈消耗的时间
5. **初相位 φ**：t=0 时刻，这个点一开始处在圆盘哪个角度位置

> 
> 正弦 / 余弦信号，就是旋转点在竖直轴上的投影！
