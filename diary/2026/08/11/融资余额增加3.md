# 一、可以考虑买入的 4 种安全情形

股价长期底部横盘，融资余额缓慢、小幅持续抬升

股价没怎么涨，杠杆资金悄悄分批建仓，属于先知资金布局，抛压小、后续拉升动力足，风险最低。

2. 上涨趋势中段，融资匀速小幅增加

股价沿着均线稳步上行，融资每天一点点加，说明趋势被杠杆资金认可，行情有延续性，属于健康加仓。

3. 融资余额占流通市值比例很低（一般＜3%）

杠杆总体量小，就算后面回调，平仓踩踏力度有限，安全边际高。

4. 有真实基本面 / 业绩 / 行业政策利好驱动

融资增加是因为逻辑硬，不是纯题材炒作、纯情绪炒作，资金持续性更强。

# 二、绝对不要碰的高危情况（90% 容易被套）

1. 股价已经翻倍 / 大幅暴涨后，融资突然短期爆炸式激增

短线散户加杠杆疯狂追高，主力大概率借机出货，一旦拐头就是融资盘连环平仓大跌，杀伤力极大。

2. 融资占流通市值比例过高（＞8%～10%）

杠杆筹码堆积如山，上方全是待兑现的抛压，稍微一点调整就会触发被动平仓，跌幅会远超普通个股。

3. 融资大增，但融券余额同步大幅飙升

多空激烈对赌，分歧巨大，接下来大概率宽幅震荡、大起大落，普通人很难把握节奏。

4. 纯题材炒作、无业绩支撑的小票爆炒

靠情绪堆起来的融资盘，利好一出、热度退潮，杠杆资金跑得比谁都快。

# 三、买这类股票必须遵守的风控规则

1. 绝不满仓，更不要自己再加杠杆

个股本身已经带大量融资杠杆，你再上融资，等于双重杠杆，一次回撤就会大亏。

2. 严格设置止损

只要放量跌破关键均线、破位下行，立刻离场，避免卷入平仓踩踏。

3. 盯后续融资余额变化

如果股价一滞涨，融资余额开始连续下降，说明杠杆资金在获利了结，马上撤退。

4. 小盘股慎之又慎

小盘股流动性差，融资盘集中卖出时砸盘效果会被无限放大。

# 极简最终口诀

低位慢增可跟踪，中段缓加可持有；高位暴增直接走，高占比例莫伸手。
