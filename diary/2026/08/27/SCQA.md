### SCQA 模型

SCQA 是**结构化表达与思考的经典框架**，出自麦肯锡芭芭拉・明托《金字塔原理》，核心是通过「情境 - 冲突 - 疑问 - 答案」的逻辑链条，快速建立共识、抓住注意力，清晰输出核心观点，广泛用于汇报、方案、演讲、文案等场景。

#### 四个核心要素

1. **S — Situation（情境）**
描述公认的背景、事实、现状，先和听众建立共识，让对方快速代入语境。

> 
> 要点：客观、无争议，是大家普遍认同的前提。
2. **C — Complication（冲突）**
情境中出现的问题、矛盾、挑战或风险，打破平稳现状，制造核心张力，引发听众的关注。

> 
> 要点：是真实的痛点，而非无中生有的问题。
3. **Q — Question（疑问）**
基于冲突自然引出的核心问题，也是听众心中会产生的疑问。

> 
> 常见疑问：怎么办？为什么会这样？如何解决？
4. **A — Answer（答案）**
针对疑问给出的核心结论、解决方案或核心观点，是你表达的最终目的。

> 
> 要点：清晰直接，给出明确的立场和落地路径。

#### 标准结构与常见变体

标准顺序：**S → C → Q → A**（循序渐进，适合完整开场）
示例（业务汇报）：

- S：公司今年核心目标是提升用户复购率，目前会员体系已覆盖 80% 活跃用户。
- C：但近 3 个月会员复购率不升反降，会员权益使用率不足 20%。
- Q：如何激活现有会员，提升复购率？
- A：优化会员权益分层，推出月度专属兑换活动，预计可提升复购率 12%。

常用变体及适用场景：

- **开门见山式（A → S → C）**：先给结论，再讲背景冲突。适合向上汇报、时间紧张的场合，优先让对方听到结果。
- **突出忧虑式（C → S → Q → A）**：先抛冲突痛点，再补背景。适合客户提案、风险预警，先抓住对方的焦虑点。
- **突出信心式（Q → S → C → A）**：先抛问题，再逐步解答。适合演讲、分享、培训开场，引发听众好奇心。
